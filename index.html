4. Signature Code System

        
The ABPS system uses two formats for rock signatures:

        
    
          
  • String Format: Compact, human-readable code for quick identification
    • 
          
  • JSON Format: Machine-readable, full details for databases and APIs
    • 
        

      


      

          
4.2 String-Based Signature

          
A Signature code with 7 parts separated by underscores. Currently developed up to 5th Tier and require 6th and 7th Tier development that addresses microscopic features:

          

              (major minerals)+[minor minerals]+{accessory minerals}_texturecodes_lithodemecode_genetic_protolith_**microscopicfeatures_mineralchemistry**
          

          

              

                  
Tier 1: Mineral Assemblages

                  
Within Parentheses ( ) Major minerals (>10%)

                  
Within Square Brackets [ ] Minor minerals (1–10%)

                  
Within curly Brackets { } Accessory minerals (<1%)

              

              

                  
Tier 2: Texture Codes

                  
_ texturecodes (e.g. Gns+Fol)

                  
Tier 3: Lithodemo Code

                  
_ lithodemecode (3–6 letters from catalogue)

              

          

          

              

                  
Tier 4: Genetic Code

                  
_ genetic (2 letters)

                  
Tier 5: Protolith Code

                  
_ protolith (2 letters)

              

              

                  
Tier 6: Microscopic Features 1

                  
Tier 7: Microscopic Features 2 / Mineral Chemistry

              

          


          
🔬 Further Developments (Tiers 6 & 7)

          
          

              
**Tier 6: Microscopic Features 1**

              


          

              
**Tier 7: Microscopic Features 2 / Mineral Chemistry**

              


          
Empty field = - → No ambiguity

      

      

        
Examples

        

          (Bt+Fsp+Qz+Sil)_FO+LI_GSgn_ME_PL

          → Khondalite with full data
        

        

          Cal+Fsp+Qz_-_CAL_-__GR

          → Calcareous rock, only minerals + protolith known
        

        

          -_-_AUG_ME_CR

          → Only rock name, genetic class, and protolith known
        

      


      

        
4.2 JSON-Based Signature

        
Full machine-readable format with explicit fields:

        

          {

            "signature_code": "(Bt+Fsp+Grt+Qz)_BA+FO_GBgn_ME_PL",

            "genetic_class": { "code": "ME", "class": "Metamorphic" },

            "protolith": { "code": "PL", "protolith": "Pelitic" },

            "rock_type_code": "GBgn",

            "lithodeme": { "name": "Garnet-Biotite Gneiss" },

            "mineral_assemblage": [ ... ],

            "texture_assemblage": [ ... ],

            "metadata": { "version": "1.0.0", "date_created": "2025-11-28" }

          }
